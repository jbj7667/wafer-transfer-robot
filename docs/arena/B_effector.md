# B — 엔드이펙터·웨이퍼 핸들링 관점 브레인스토밍

## 전제 치수 (모든 아이디어 공통)
- CD Ø120×1.2, 중심홀 Ø15, 16g(0.157N). 베이스 상단 Ø50 위에 얹힘 → **CD 반경 25~60mm 링(돌출부)의 아랫면은 비어 있음**. 접근 방향(행 라인)에서 보면 CD 아래 빈 공간은 z=100(하단 원기둥 윗면)~175/200.
- **2위치 승강 하나로 두 높이 모두 처리 가능**: 진입 높이 z=160(포크 윗면 166 < 175, 하단 원기둥 100보다 위), 들어올림 높이 z=215(200 베이스에서도 CD가 15mm 뜸). 같은 행 두 베이스는 높이가 같으므로 내려놓기도 같은 2위치(215→160)로 끝남. 높이 판별이 필요 없음. 스트로크 55mm.
- 표준 포크: 두 갈래 안쪽 간격 70(Ø50 원통 대비 횡 여유 ±10), 갈래 폭 12, 두께 6(PETG), 갈래 길이 150. y=±35~47 위치의 CD 현은 반길이 37~46mm라 CD 받침 길이가 충분.
- 정지선은 베이스 중심 100mm 앞이고, 하단 원기둥(R50) 앞면까지는 50mm 남음. 포크 끝은 라인센서 기준 약 +140mm(베이스 중심 +40)까지 나가야 함. 몸체가 z<100 높이에서 50mm 이상 앞으로 나가면 하단 원기둥과 부딪침.
- 180° 제자리 회전 시 CD가 회전중심에서 150mm 떨어져 있고 ω≈3rad/s이면 원심가속도 ≈1.35m/s²(0.14g). PLA–CD 마찰계수 μ≈0.2~0.3이므로 **평판 위에 올려만 두면 미끄러질 수 있는 경계값**. 포켓/구속이 필요함.

## 내 관점 상위 5개
1. **B03 C-링 림 포켓 패들**: 개구 70 < CD Ø120이라는 기하만으로 수평 이탈을 원천 차단해 회전 중 CD 이탈(타 팀 빈발 문제)을 해결함. 부품은 출력물 하나뿐이고 모터도 승강 1개라 1인 제작에 가장 단순한 고신뢰 구조.
2. **B02 원추 시트(자기중심)**: B03과 같은 부품에 8° 경사만 추가하면 픽할 때 생긴 ±10mm 오차가 포크 위에서 ±1로 정렬됨. 플레이스할 때 CD가 베이스 중심에 오도록 하는 열쇠이고, B06 홀 인덱싱으로 확장도 가능.
3. **B25 부유 웨이트 캡**: 모터·센서·타이밍 없이 수직 구속(점프·진동 대비)까지 더함. B03/B02 포켓과 겹쳐 쓰면 "수평은 기하, 수직은 중력"으로 구속이 완성되고, 실패 모드가 거의 기계적 걸림 하나뿐.
4. **B09 플로팅 순응 포크**: 라인추종 횡오차 ±8에 갈래 여유 ±10은 빠듯하고, 베이스가 고정돼 있지 않아 닿으면 바로 실패함. 롤러와 플로팅으로 "닿아도 밀지 않게" 만들어 정렬 허용오차 점수(20)를 직접 끌어올림.
5. **B19 돌출 링 IR 하향 판별**: 본선에서 좌/우 무작위를 센서로 판단해야 하는데, CD 돌출 링 아래는 75mm 이상 비어 있어 IR 거리값 차이가 크고 확실함. 포크 동작 없이 0.1초에 판단하므로 B20 탐촉보다 빠르고 기계적 리스크도 없음.

## 다른 관점과 결합 메모
- **2위치 승강(160/215) 원칙은 구동 관점(A 등)과 꼭 공유할 것**: 높이 판별이 필요 없으므로 리드스크류든 크랭크든 상·하 리밋SW 2개로 충분하고, 하단 리밋이 그대로 "센서 기반 자체 초기화" 가점 근거가 됨.
- B22 평행링크는 구동 관점의 "평행 링크"와 같은 하드웨어지만, 이펙터 쪽 이점(회전 시 CD를 회전중심으로 회수해 원심 0.14g → 0.03g)을 근거로 채택 여부를 판단할 것.
- 상부형(B13~B18, B23)은 B23 접촉 하강을 반드시 함께 써야 하고, 높이차 1.2mm로는 CD 유무를 판별할 수 없음 → 센서 관점의 B19류 IR 판별을 함께 써야 함.
- RE-260 팬 계열(B14, B18)은 전장/노이즈 관점과 결합 필요: 모터 전원 분리, 0.1µF 3개 + 100µF, 페라이트. 이미 보고된 Mega 리셋 문제를 키울 수 있음.
- 다중 적재(스택)는 검토 결과 경로상 이득이 없음(행별 "한쪽 픽 → 직진 횡단 → 플레이스"와 "왼쪽 3장 모두 픽 → 오른쪽 3장 모두 플레이스"의 주행 거리가 같고, 회전 횟수만 늘어남). 그래서 표에서 뺐음. 경로 관점에서 다른 동선을 쓸 때만 재검토.
- B21 범퍼 기준은 주행 관점의 정지선 ±5 가정을 ±2로 줄일 수 있지만, 베이스가 밀리는 리스크 때문에 접촉력 0.3N 이하 저속 접근 프로파일과 짝을 이뤄야 함.
