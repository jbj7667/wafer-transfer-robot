# 배선도 (v1)

핀 번호의 기준은 `public/firmware/wafer_robot/config.h`이다. 펌웨어와 이 문서가 다르면 config.h가 우선이며, 이 문서를 갱신한다.
넥 접촉 스위치 핀은 펌웨어에서 추가 중이므로 **"config.h 참조"**로 표기한다.

## 1. 시스템 구성도 (ASCII)

```
                       +------------------------------------------+
   [스마트폰 앱] <-BLE-> [HM-10] --Serial3(D14/D15)--+              |
   (출발, 전압)                                      |              |
                                                     v              |
 [푸시버튼 D19] --------------------------->  +--------------+      |
 [하한 리밋 D2] / [상한 리밋 D18] ---------->  |              |      |
 [넥 접촉 스위치 (config.h 참조)] ---------->  | Arduino Mega |      |
 [라인센서 L/C/R D22/D24/D26] -------------->  |    2560      |      |
 [(선택) 초음파 D23 / D3] ---------------->  |   (제어)     |      |
 [IR 상향 GP2Y0A41 A0] --------------------->  |              |      |
 [분압 A2 (제어팩) / A3 (모터팩)] ---------->  |              |      |
                                               |  D44,D45 PWM |----> [L298] --> DC모터 좌/우
                                               |  D30~D33 DIR |
                                               |  D36,37,38   |----> [DRV8834] --> 스테퍼 SF2421 --> 리드스크류 --> 포크
                                               |  D40         |----> [외관 LED]
                                               +--------------+
```

## 2. 전원 구성 (두 팩 분리, 공통 접지)

```
 [AA x6 건전지 약 9V]--SW1--+--------------- Mega VIN (DC잭/VIN)  (Mega 내장 레귤레이터 -> 5V)
   (제어용 팩)              +--[20k]--+--[10k]--GND
                                     +--------> A2   (9.6V -> 3.2V)

 [AA x6 충전지 약 7.2V]--SW2--+--[퓨즈/옵션]--+--> L298 모터전원(+12V 단자) --> DC모터 L/R
   (모터용 팩)                |               +--> DRV8834 VMOT (100uF 전해 근접 실장) --> 스테퍼
                              +--[20k]--+--[10k]--GND
                                         +--------> A3   (7.2V -> 2.4V)

 GND: 제어팩(-), 모터팩(-), L298 GND, DRV8834 GND를 Mega GND 한 점(스타 접지)에서 공통
```

- 팩마다 독립 스위치(SW1, SW2)를 둔다(규정). 두 팩의 (+)는 절대 연결하지 않는다. GND만 공통.
- 모터 소음 대책: 각 DC모터 단자 사이 0.1µF 세라믹, 모터선은 꼬아서 배선, DRV8834 VMOT와 GND 사이에 100µF 전해(극성 주의), L298 전원 입력에도 100µF 권장.
- 전해 콘덴서 극성: 긴 다리 (+) → VMOT, 짧은 다리/띠 표시 (-) → GND.

### 2.1 전압 분배기 (20k/10k, 1/3 분압)

| 대상 | 회로 | ADC 핀 | 정상 입력 | 비고 |
|---|---|---|---|---|
| 제어팩 (9V) | 팩(+) -- 20kΩ -- A2 -- 10kΩ -- GND | A2 | 9.6V일 때 3.2V | 신품 알칼리 AA 6개 약 9.6V |
| 모터팩 (7.2V) | 팩(+) -- 20kΩ -- A3 -- 10kΩ -- GND | A3 | 7.2V일 때 2.4V | NiMH 만충 약 8.4V → 2.8V |

- 펌웨어 환산: `V = ADC * 5/1023 * 3` (`VBAT_SCALE`), 멀티미터 실측으로 `VBAT_CAL_*` 보정.
- 분압 중간점에 0.1µF를 A2/A3-GND 사이에 달면 ADC 잡음이 줄어든다(선택).

## 4. DRV8834 전류 제한 설정 절차

공식 근거: Pololu DRV8834 캐리어 상품 페이지 (https://www.pololu.com/product/2134). 전류 제한 공식은 `I_limit = VREF × 2` (센스 저항 0.100Ω 캐리어 기준)이다. 예: 1A 제한 → VREF 0.5V. 풀스텝에서 두 코일이 모두 켜질 때 실측 코일 전류는 제한값의 약 70%다.

1. 모터 정격 전류 확인(SF2421: 지급 사양서/실측 상저항 기준). 설계 기준은 보유 전류 0.4A (`mechanism.md` 5절). 이 경우 **VREF = 0.4 / 2 = 0.20V**.
2. 모터팩 SW2 Off 상태에서 로직(5V)만 켠다. 모터는 연결 전 또는 연결된 채로 해도 되지만 **통전 중 모터 커넥터를 뽑지 않는다**(드라이버 손상).
3. 멀티미터를 DC V로 놓고 (-) 프로브를 GND, (+) 프로브를 캐리어 가변저항(전위차계) 금속부(또는 VREF 패드)에 대고 작은 드라이버로 돌려 목표 VREF에 맞춘다.
4. 풀스텝으로 승강을 구동하며 발열을 확인한다. 드라이버가 과열되면 VREF를 낮춘다(리드 8mm, 하중 약 80g이므로 낮은 전류로도 충분).
5. 값을 기록한다(보고서 부록): 날짜, VREF, 계산 전류, 발열 상태.
- 주의: Pololu 포럼에는 일부 캐리어에서 VREF 최솟값이 0.55~0.64V 부근에서 더 내려가지 않았다는 보고가 있다(전류 약 1.1~1.3A 하한). 0.20V까지 내려가지 않으면 **전류 하한이 높다는 뜻**이므로, 스테퍼 정격 이내인지 확인하고, 모터 발열이 크면 승강 가속도·홀딩 시간을 줄이거나(필요 시 nSLEEP로 유휴 시 차단) 정격이 허용하는 최소로 사용한다.
- 홀딩이 필요 없는 시점(대기·주행 중)에는 nSLEEP=LOW로 소비 전류를 줄일 수 있다. 단 SLEEP 후에는 위치 유지가 안 되므로, 펌웨어가 위치 유지를 요구하는 구간에서는 HIGH 유지(config.h의 PIN_SLEEP 동작 참조).
- 참고 출처: [Pololu DRV8834 캐리어](https://www.pololu.com/product/2134-based), [Pololu 포럼: VREF 최솟값 보고](https://forum.pololu.com/t/drv8834-vref-minimum-voltage-too-high-0-55-0-64-v-on-pololu-carrier/29178).

## 5. L298 모듈 점퍼 (7.2V 모터 전원)

- 모듈에는 보통 (1) ENA/ENB 점퍼(PWM 핀 쪽), (2) "5V-EN" 레귤레이터 점퍼가 있다.
- **ENA/ENB 점퍼는 제거**하고 D44/D45를 연결한다(점퍼를 두면 항상 100% 구동이라 PWM 제어 불가).
- 7.2V 팩에서는 모듈 내장 5V 레귤레이터(78M05 계열)가 입력 약 7V 이상을 요구하고 NiMH 방전 시 6.6V 이하로 내려가므로 5V가 불안정해진다. 따라서 **5V-EN 점퍼를 제거**하고, 모듈 로직 5V 단자는 Mega 5V에서 공급한다(출력으로 쓰지 않음).
- L298 내부 전압 강하(약 2V) 때문에 모터에 걸리는 실제 전압은 약 5V다. 속도가 부족하면 `SPEED_*`를 올리거나 Q2(TB6612FNG) 질의 결과를 따른다.

## 6. 라인센서 전원 선택 (5V vs 3.3V)

- 학과 라인센서 튜닝 안내서의 순서를 따른다: 전원(5V ↔ 3.3V) → 센서 높이 → 기울기 → 차광. (안내서 원문은 비공개 자료로 이 저장소에 없음)
- 기본은 5V로 시작한다. 인쇄 라인에서 흰 바탕이 흑으로 오인되거나 검은 선이 안 잡히면 3.3V(Mega 3.3V 핀, 최대 50mA)로 바꿔 비교한다.
- 3.3V로 구동하면 센서 출력 HIGH가 약 3.3V이며 Mega는 약 3.0V 이상을 HIGH로 읽으므로 여유가 작다. 3.3V에서 흰 바탕 판독이 흔들리면 5V로 복귀한다.
- 결정 후 사용 전압, 높이(8~12mm), 측정 사진을 보고서에 기록한다.

## 7. 노이즈·접지 주의

- 별도 팩, GND만 한 점(Mega GND)에서 합친다. 모터 전류가 지나는 GND선과 센서 GND선을 한 점에서 분기(스타)하고, 모터 쪽은 굵은 선.
- DRV8834 VMOT 100µF, L298 전원 100µF, 각 DC모터 0.1µF, 스테퍼 상 코일선은 꼬아 배선.
- 리셋이 나면 PIN 연결 외에 팩 전압 강하(앱 전압 표시)부터 확인한다.
