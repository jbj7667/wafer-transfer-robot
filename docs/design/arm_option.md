# 팔 방식(θ-R-Z) 공학 분석 — arm_option (PLAN_v2 §2, 작업 2-1)

작성 2026-10-27. 대상: 포크+승강축 1개(현재 설계, `mechanism.md`)의 대안인 **정지점 S에서 3축 팔로 6개 베이스를 모두 처리하는 로봇**.
수치 표는 `arm_calc/*.py`(실행: `python -I 파일.py`)가 만들고 출력은 같은 폴더의 `*_out.md`에 저장돼 있다. 상수만 바꿔 다시 돌리면 이 문서의 표가 갱신된다.

표기: **[계산]** 입력이 확정값인 순수 계산, **[가정]** 내가 둔 입력(바꾸면 결과 변동), **[확인필요]** 사용자가 실측·확인해야 결정되는 값.

### 1.1 좌표와 표 (S=(500,240), 로봇 헤딩 북쪽(−y), θ 왼쪽 +, 원점 왼쪽 위·+y 아래) [계산]

- 헤딩은 **순수 가로 오차** R·sin(e): 0.5°→3.4, 1°→6.7, 2°→13.5, 3°→20.2mm (R=386) [계산]. 트렁크 방향 오차는 **가로 9.6 + 깊이 2.8**로 나뉜다. 횡 오차는 거의 깊이로만 들어간다.
- 가로 예산(상단 행, 보정 없음): 트렁크 9.6 + 횡 1.4 + 헤딩 13.5 = 선형합 24.5mm, 제곱합 16.6mm → **U 허용 ±14 초과** [계산].
- 깊이 오차(최대 6.6 + R 반복 오차 약 3)는 원추 시트 ±10 안에 들어간다. 더 확실히 하려면 포크 U 바닥에 mechanism.md와 같은 **넥 접촉 레버 스위치**(리밋류는 센서 제한 대상 아님)를 달아 접촉까지 삽입하면 깊이 오차가 0이 된다 [권장].
- 트렁크 방향 정지오차는 직진 후 65mm 크리프 시간으로 잡는다. 엔코더가 없으므로 속도 변동 10% 가정이면 ±6.5mm [가정]; 검출 지연 1mm를 더해 ±7mm로 둔다. 가로 7mm + 횡 1.4 + 헤딩 잔차 3 = 선형합 11.4mm로 14 안(여유 2.6mm) [가정].
- **S 기준점 주의**: S는 회전대 축 위치다. 라인센서가 축보다 x_s−x_T 앞에 있으므로 중단 행선 이벤트 후 전진 거리 = 65 + (x_s − x_T)이다 (예: 센서 +25, 축 +5이면 85mm) [계산].

### 1.3 방향(헤딩) 오차 보정

중단 행선(y=305, 폭 19)을 지날 때 센서의 좌·우 **외곽 채널**이 라인을 밟는 시각 차 Δt = t_left − t_right 로 추정한다 (1 kHz 틱에서 측정).

```
ψ = atan( v · Δt / d )          (ψ > 0: 로봇이 반시계(왼쪽)로 틀어짐 → 오른쪽 채널이 먼저 밟음)
θ_cmd = θ_nom − ψ               (K4: 헤딩 +2°일 때 필요 dθ = −2.00°. 부호는 시제품에서 확인필요)
v: 교차 구간 저속 통과 속도 (엔코더 없음 → 틱 간 거리는 PD 출력으로 추정 또는 고정 PWM 속도 보정값)
d: 외곽 채널 간격 [확인필요: YwRobot S033, PCB 66mm 중 채널 간격을 실측]
```

분해능과 정확도 [계산, d·지터는 가정]:

| d (mm) | 틱 분해능 (v=100~150mm/s) | 에지 지터 j=0.5mm: 1에지 / 4에지 평균 | j=1.0mm: 4에지 평균 | 386mm 팔끝 (j=0.5 / 1.0, 4에지) |
|---|---|---|---|---|
| 40 | 0.14~0.21° | 1.01° / 0.72° | 1.43° | 4.8 / 9.6 mm |
| 48 | 0.12~0.18° | 0.84° / 0.60° | 1.19° | 4.0 / 8.0 mm |
| 60 | 0.10~0.14° | 0.68° / 0.48° | 0.95° | 3.2 / 6.4 mm |

- 지배 항은 **시간 분해능이 아니라 채널 에지 지터**(디지털 74HC14 임계값 고정). 라인 폭 19mm이므로 **상승·하강 에지 4개**를 모두 기록해 평균하면 지터가 1/√2.
- 목표 잔차 ≤0.6° (팔끝 약 4mm). 교차점 통과 중에는 PD를 동결하고 직진(조향 0)하여 통과 중 요(yaw) 변화를 막는다. 교차 후 65~85mm 직진 동안 요 표류는 ±0.3° 가정 [가정].
- 추가 완화: (a) 하단 행선과 중단 행선 두 번 측정해 평균(bottom 교차→middle 교차 사이 요 변화가 작음), (b) 시제품에서 ψ 추정치와 실제 헤딩(종이 위 펜 자국 2점)을 10회 비교해 교정 계수 산출.
- 보정이 부족하면 대안: 첫 베이스 접근 시 포크 IR로 θ ±3° 스윕, 넥 반사 최대각을 찾아 θ를 국소 미세조정(IR 2번째 개수 한도 내) [아이디어, 미검증].

## 2. 벨트·풀리 설계 (GT2, 피치 2mm, 폭 6mm)

수치는 `arm_calc/belt_out.md`. PD = 2·T/π, 벨트 길이 L = 2C + π(D+d)/2 + (D−d)²/4C, C = 축간거리.

### 2.1 연동 원리 (유도 확인) [계산]

- 어깨 축에 **고정 풀리 P_s**(회전대에 붙음, 안 돌아감), 링크1이 어깨에서 φ만큼 돌면 팔꿈치의 **P_e1**(링크2에 고정)은 링크1 기준 −φ·(r_s/r_e)만큼 돈다. 링크2 절대각 = φ − φ·r_s/r_e. 손목 반경 방향 직선 운동이 되려면 링크2 절대각 = −φ → **r_s/r_e = 2** (어깨:팔꿈치 = 2:1).
- 팔꿈치 축에 링크1에 고정된 **P_e2**(P_e1과 같은 축, 별도 풀리), 손목에 포크와 함께 도는 **P_w**. 포크 절대각 = 0 이 되려면 **r_w/r_e2 = 2** (팔꿈치:손목 = 1:2).
- 따라서 풀리 2쌍(어깨 2T : 팔꿈치 T, 팔꿈치 T : 손목 2T)이고 벨트 2개의 길이는 같다. 링크 내부(속 빈 상자)에 벨트가 지나간다.
- 구동: 별도의 **R 구동 벨트**(R 모터 풀리 → 링크1 어깨 풀리, 3:1)가 링크1을 돌린다. 이 풀리는 P_s와 같은 축에서 링크1에 고정, P_s는 회전대에 고정 — 어깨 축에 풀리 2개 + 베어링 2개 스택이 된다.

### 2.5 백래시·장력·텐셔너

1. **증폭**: 링크2 상대각 오차 = 총 슬랙 s / r_e, 팔끝 변위 = L·s/r_e. 팔꿈치 풀리가 작을수록 크다 [계산]:

   | 팔꿈치 T | r_e (mm) | 증폭 L/r_e | s=0.1 | s=0.2 | s=0.4 (팔끝 mm) |
   |---|---|---|---|---|---|
   | 15 | 4.77 | 42.9 | 4.3 | 8.6 | 17.2 |
   | 20 | 6.37 | 32.2 | 3.2 | 6.4 | 12.9 |
   | 26 | 8.28 | 24.8 | 2.5 | 5.0 | 9.9 |
   | 30 | 9.55 | 21.5 | 2.1 | 4.3 | 8.6 |

   → 팔꿈치 쌍은 **26T(52T:26T) 이상**을 권장하고, 슬랙 s ≤ 0.1~0.15mm를 목표로 한다. 손목 단은 포크 헤딩에만 영향(링크2 오차의 1/2, 포켓 오프셋 64mm이므로 팔끝 영향 <1mm) [계산].
2. **한 방향 접근 규칙**(펌웨어): 모든 정지 목표는 같은 회전 방향에서 도달한다. R은 항상 "펴는 방향"으로, θ는 항상 "후방에서 전방 쪽(감소)" 방향으로 마지막 1° 접근. 슬랙이 양방향 히스테리시스가 아니라 상수 오프셋이 되어 사실상 제거된다. 비용: 접근마다 약 0.15s.
3. **선장력**: 목표 10~15N [가정]. 현장 측정은 중앙 처짐법: 스팬 205mm 중앙에 100g 추를 달 때 처짐 = F·스팬/(4T) → T=10N 5.1mm, 12N 4.3mm, 15N 3.4mm [계산]. 축 하중은 약 2T = 20~30N, 608 충분.
4. **텐셔너**: ① 팔꿈치 축 블록을 링크1 내부 슬롯(M3 ×2, 행정 ±3mm)에 두고 M3 밀기 나사로 C를 조정(벨트1), ② 손목 축 블록을 링크2 슬롯에 두고 동일(벨트2), ③ θ 벨트는 모터 슬롯 ±3mm. 아이들러(608을 벨트 뒷면에 대는 방식)는 뒷면 굽힘 반경 11mm로 가능하지만 접촉각이 늘어 마찰이 커져 권장하지 않는다.
5. **인쇄 풀리**: GT2 이빨 0.75mm 깊이는 0.4 노즐·0.1~0.15 레이어에서 겨우 재현. 이빨 피치 오차 ±0.1mm이면 벨트 100T 감김에서 슬립(점프) 가능성. 시험에서 벨트를 걸고 풀리를 손으로 흔들어 **이빨 유격**을 먼저 확인(필러 게이지로 0.1mm 이하). PLA는 장력 하에서 크리프하므로 팔꿈치 풀리는 PETG.
6. **허브**: 풀리 고정은 세트 스크루가 아닌 D컷 또는 M3 압입 너트+볼트로 (인쇄물 축 미끄러짐 방지).

### 3.4 전도 안정성 (정적) [계산, 질량 분포는 가정]

좌표: 바퀴축 중점 원점. 접지점: 구동륜 (0, ±92) (바퀴 외측 폭 210, 바퀴 폭 26), 후방 볼 캐스터 (−75, 0) (params.md). 회전대 축 x_T(축 위치) 변화에 따른 6개 뻗음 자세 + 후방 운반 + 접힘 자세의 지지 다각형까지 최소 거리(mm). 음수 = 전도. 목표 ≥ +20mm.

| 구성 | 접지점 | x_T=−30 | x_T=0 | x_T=+20 | x_T=+40 |
|---|---|---|---|---|---|
| A | 구동륜 2 + 후방 캐스터 1 | 최소 +3 (상우) | **−13** | −24 | −35 |
| **B** | A + 전방 스키드 2 (x=+95, y=±70) | 최소 +27 (하좌) | **+40** | +48 | +57 |
| C | 구동륜 + 전방 스키드 (x=+80, y=±85) + 후방 캐스터 2 (x=−70, y=±60) | +40 | +56 | +56 | +45 |

- 결론: A로는 불가. **B(전방 스키드 2개)로 x_T 0~20이면 모든 자세에서 +40 이상**. 차체 CoM x ≈ −20 (배터리 후방), 마스트·승강대가 앞으로 가므로 합성 CoM은 +5~+25 구간 [계산]. 팔이 옆을 향하는 상단 행 자세(θ=±73°)의 가로 여유 최소 약 44mm.
- 스키드 권장 위치: x=+95, y=±70 (트렁크 선 19mm 양옆에 걸쳐 지나가고, 팔 방식은 로봇이 베이스에 접근하지 않으므로 하단 원기둥과 간섭하지 않음). **볼 캐스터를 지면보다 1~2mm 띄워** 정상 주행에는 닿지 않고 전도 시에만 접촉하게 한다 (교차점·곡선 라인 걸림 방지). 3/8" 볼 캐스터 +2개 (로봇 전체 3개).
- 접힘 외곽 때문에 L=205/190의 축 위치(y=−68 또는 x=+90)는 위 계산 범위(x_T ≤ +40, y=0)를 벗어난다. 이 위치는 CoM이 좌우 또는 전방으로 크게 치우쳐 스키드 재배치와 재계산이 필요하다 [확인필요: 미계산]. 이 점도 L=180 중앙 배치를 권고하는 근거.
- 동적: 팔 가속이 CD 슬립 한계(0.2g) 이하이므로 CoM 이동은 정적 오차의 수 mm 이내. 정차 중 팔 동작만 하므로 주행 가감속과 중첩 없음.

- 접힘(출발) 상태 치수: **L=180** 기준 팔 외곽이 250×250 정사각형에 대각선(θ_stow≈216°)으로 들어감 — 계산상 외곽 250 이하(여유 거의 0), 높이 ≤ 245, 폭·길이는 params.md의 x_rear −92 ~ x_front +158(250)으로 한정. **Fusion 간섭 검사(2-2)로 확정 필요**.

## 4. 동작 계획과 시간 (`arm_calc/motion_out.md`)

### 4.1 전체 흐름

1. 전원 → 3축 원점(§5.3) → 시작(버튼/BLE) → 라인추종으로 트렁크 진행 → 하단 행 교차점(1번째) 통과 → **중단 행 교차점(2번째)에서 방향 추정(§1.3)** → 65+(x_s−x_T)mm 전진해 **S 정지**.
2. S에서 3행 처리(상단→중단→하단 순서 또는 가까운 쪽 우선; 아래는 상→중→하 가정). 이후 팔 접기, 180° 제자리 회전, 라인추종으로 출발 구역 복귀.
3. 팔은 로봇이 S에 멈춘 뒤에만 움직인다 (주행과 팔 동작 비중첩).

### 4.2 한 CD 사이클 (좌 → 우, 예선)

### 4.4 경로 규칙과 경계·간섭 점검 [계산]

- **회전은 항상 후방(남쪽) 경유**: 좌→우는 θ 증가 방향, 우→좌는 감소 방향. 전방(북쪽) 경유는 회전각이 짧지만 R_C=200에서 CD 가장자리가 y=240−200−60 = −20으로 자기 구역 밖으로 나가므로 사용하지 않는다.
- **운반 반경 R_C=200 (손목 136, φ=70.6°)**: CD 궤적 고리 반경 140~260, 가장 가까운 베이스 넥/기둥은 S에서 326.5 이상(기둥 반경 50 → 276)이라 운반 중 **어떤 베이스와도 평면상 겹치지 않는다**. 즉 "기둥 윗면+CD" 간격이 문제 되는 구간은 삽입·후퇴·내림의 짧은 구간뿐이다. 그 구간의 포크 아랫면(윗면 −4)은 운반 높이에서 기둥 윗면+11, 다른 베이스 위 CD 윗면(201.2 / 상단 행 176.2)과 약 9.8mm 간격 [계산].
- **팔꿈치 원 (반경 L, 회전대 축 중심)**: 팔꿈치 가지 s=+1에서 운반 중 팔꿈치 방향 범위와 y 최소 [계산]:

  | 행 | 운반 팔꿈치 방향 | 팔꿈치 중심 y_min | 보스 r20 가장자리 | 링크 가장자리(반폭 14) |
  |---|---|---|---|---|
  | 상단 | 144~357° | **35.2** | **15.2** | 21.2 |
  | 중단 | 172~329° | 64.0 | 44.0 | 50.0 |
  | 하단 | 202~299° | 140.6 | 120.6 | 126.6 |

  → y_min = 240 − L (L=205 → 35, L=180 → **60**, 보스 가장자리 40). S가 북쪽으로 10mm 틀어지면 L=205에서는 가장자리 5mm까지 줄어든다. 구역 경계 침범 판정이 바닥 투영만인지(공중 부분은 무관인지) 규칙 확인필요(rules.yaml에는 상대 구역 침범 조항 없음; OP 문서 재확인). **L=180이면 안전 여유 40mm**가 확보되는 점도 L 축소 근거.
- **링크–넥 간섭** (z: 링크 118~160, 넥 상단 175/200 → 겹칠 수 있음): 픽 자세에서 링크 중심선과 6개 베이스 중심 거리 최소 = 링크1 130~258, 링크2 64(대상 베이스, 손목이 포켓에서 64) → 필요 39(넥 25+반폭 14)를 모두 충족 [계산]. 단, 손목 허브(r20)가 CD 아래이므로 §3.5의 적층 한도를 지켜야 한다.
- **들어올림 높이**: 운반 시 포크 윗면 = 기둥 윗면+15 (200 → 215, 175 → 190). 내릴 때 포켓 중심이 기둥 중심에서 ±14mm 안이어야 하며 원추 시트가 ±10 흡수.

### 4.5 CD 이탈 점검 (운반 중) [계산, 마찰계수는 가정]

- R_C=200, 150°/s: 구심 1.37 m/s², 접선 1.57 m/s² (450°/s²), 합성 2.08 m/s² = 0.21g. PETG–CD 마찰계수 0.3~0.4 [가정, 확인필요]로 마찰만으로는 경계 영역 → 림 턱(2mm) 기하 차단이 주 방어이며, 가속 구간을 램프로 처리한다. 시제품에서 150→100→200°/s로 바꿔가며 CD가 포켓에서 이동한 양을 측정.
- R 가속은 2 m/s²(0.2g)로 제한.

## 5. 제어

### 5.1 타이머 배정 (Mega 2560)

| 타이머 | 용도 | 비고 |
|---|---|---|
| Timer0 | millis/delay (Arduino 기본) | 변경 안 함 |
| Timer1 | 1 kHz 제어 틱 (라인센서, PD, 상태머신, 가감속 프로파일 갱신) | 기존 설계 유지 |
| Timer5 | 구동 모터 PWM (핀 44~46) | 기존 유지 |
| **Timer3** | **스텝 생성: CTC 20 kHz 단일 ISR + DDA 3축** | θ·R·Z 동시, 새 사용 |
| Timer4 | 예비 (Z 전용 분리 시, 또는 홈잉 저속 스캔) | |
| Timer2 | 예비 (8비트) | |

- 이유: PLAN 2-4가 "1개 타이머 ISR에서 3축 동시 스텝 생성"으로 규정했고, 기존 Timer1(제어 틱)과 Timer5(PWM)를 건드리지 않는다. Timer3의 출력 비교 핀을 쓰지 않고 ISR 안에서 STEP 핀을 직접 토글한다.
- DDA: 축마다 16비트 위상 누산기, 증분 = v[sps]·65536/20000. 위상이 넘치면 STEP 상승 → 다음 ISR에서 하강(펄스 폭 50 µs ≥ DRV8834/TMC2208 최소 펄스). STEP 3개를 같은 포트(예: PORTA 22·23·24)에 배치해 한 번의 포트 쓰기로 처리, DIR/ENABLE도 포트 정리.
- 최대 스텝률 [계산]: θ 2000 sps (1/8 마이크로스텝, 150°/s), R 1205 sps (1/8, 400mm/s, φ=38.2°), Z 3000 sps (1/4, 30mm/s) → **합 6205 sps**. 한 축 최대 10 kHz까지 가능 (여유 3배 이상). ISR 약 120 사이클 [가정]이면 20 kHz에서 CPU 약 15%.
- 1 kHz 제어 ISR이 스텝 ISR을 지연시킬 수 있다 (최악 100µs 미만이면 스텝 주기 500µs 대비 20%). 제어 ISR 안에서 `sei()`로 중첩 허용하거나 팔 동작 중에는 라인센서 PD를 중단(팔은 정지 후만 동작)하여 문제를 없앤다 [계산 가정].
- 마이크로스텝: DRV8834는 M0/M1(3상태), TMC2208은 MS1/MS2로 1/8 또는 1/16. TMC2208(스텔스초프)은 소음이 작고 보간(256) 가능 [확인필요: 학과 지급 허용 범위·재고].

### 5.2 소프트 한계와 좌표

| 축 | 좌표 | 소프트 한계 | 비고 |
|---|---|---|---|
| θ | 홈(접힘 θ_stow)=0, 로봇 방위 θ와 연결 | 방위 60°~300° | 전방 섹터(마스트) 진입 금지 |
| R | φ (링크1 각), 손목 반경 R_w = 2L·cosφ | φ_min + 1° ~ 105° | φ_min=35.9° (L=205 도달 + 오차), 홈 스위치 = 105° 쪽 |
| Z | 하단 리밋=0 | 0 ~ 60mm | 행정 60, 상단 리밋은 과주행 보호 |

### 5.3 3축 원점 (추가기능 ④ 초기화) [설계 제안]

- **리밋 스위치 배치 (롤러 마이크로 스위치 3~4개)**
  - Z: 하단 = 캐리지 판이 눌러 포크 윗면 155(원점) 위치, 상단 = +60 위치 (mechanism.md/params.md의 캐리지 리밋 재사용).
  - R: 링크1이 접힘 끝(φ=105°)에서 회전대 판 위 스위치를 누름. 반대쪽(φ_min)은 소프트 한계 + 선택적 과주행 스위치.
  - θ: 섀시에 고정한 롤러 스위치를 회전대에 붙인 캠이 θ_stow에서 누름 (홈 위치에서 눌린 상태).
- **전원 인가 시 순서** (전원 ON → 초기화 → 대기 → 시작)
  1. Z 하강 15mm/s → 하단 리밋, 2mm 상승, 저속 재접근 (약 4.9 s)
  2. R 접힘 방향으로 회전 → 접힘 스위치 (약 1.8 s)
  3. θ: 스위치가 눌려 있으면 완료(보통 출발 자세가 접힘이므로 미세 이동만), 아니면 한 방향 탐색(최대 120°, 30°/s, 약 4.6 s) 후 시간 초과 시 반대 방향 탐색
  4. 모두 완료 후 LED로 "준비" 표시, 시작 신호 대기
  - 총 약 3~11 s. 접힘이 출발 자세이므로 정상 출발에서는 **출발 상자 250³ 안에서만 움직임** [계산 가정]. 이동 중 재시작(터치 후 재배치) 때는 R→θ 순서로 안전하게 접는 과정이 포함된다.
  - 어느 단계든 시간 초과이면 FAULT(LED 빠른 점멸)로 시작 거부. 센서(리밋) 기반 초기화이므로 추가기능 ④ 요건("RC서보 단순 구동 불가, 센서 기반")을 충족 [확인필요: 심사관 시연 방식].
- **정지 후 위상 문제**: ENABLE을 껐다 켜면 로터가 풀스텝 위치로 끌려가 θ에서 0.6°(R=386에서 약 4mm) 어긋날 수 있다. 팔 동작 중에는 enable 유지, 비활성화한 뒤에는 반드시 재홈잉.

| 정지 홀딩만 | 0.86 | 0 | 0.86 | 6.98 V |
| 팔 이동 | 1.21 | 0 | 1.21 | 6.90 V |
| 주행(스테퍼 홀딩) | 0.86 | 0.80 | 1.66 | 6.78 V |
| 주행 가속 피크 | 0.86 | 2.00 | 2.86 | 6.48 V |

- 마이크로스텝 정지 시 코일 손실은 I_max²·R(두 코일 합) = 0.7²×3.6 = 1.76W → 스테퍼 1개 약 0.29A [계산]. 이동 시 약 1.4배 [가정].
- **전원 구성**: 모터 팩(NiMH 7.2V)은 스테퍼·DC·L298 전용. Mega는 별도 AA 팩(requirements.md 규정대로 2팩 분리)이라 스테퍼 스위칭 노이즈·전압 강하로 **Mega가 리셋되지 않는다**. DRV8834 최소 VMOT 2.5V, L298 강하 약 2V 감안해도 6.5V 팩에서 DC 모터 유효 4.5V (주행 속도 저하 확인필요 — 포크 방식과 동일 조건).
- 각 드라이버 VMOT에 100µF 이상 전해 + 0.1µF 세라믹, 배선 5cm 이내. 모터 팩 퓨즈/스위치 정격 ≥ 3A.
- **SLEEP/ENABLE 전략**: DRV8834의 SLEEP은 인덱서를 리셋하고, nENBL은 위상을 유지하지만 로터가 최근접 풀스텝 극으로 끌려가 θ에서 0.6°(팔끝 약 4mm), R에서 약 0.4° 어긋날 수 있다. 따라서 ① **홈잉 후 임무 종료까지 3축 모두 ENABLE 유지**(Z는 자기 유지 안 되므로 필수), ② 대기·충전·조작 중에는 disable하고 다음 사용 때 재홈잉, ③ 주행 중 θ·R은 접힌 자세 고정이므로 disable 후 재홈잉 시간(약 7s)과 정확도 손실 사이 선택 — 기본은 ENABLE 유지(0.86A × 약 20s 주행 = 5mAh, 미미).
- **런타임 [계산]**: 임무 1회 전하량 약 14mAh → 팩 1520mAh(1900mAh × 80%) 기준 약 107회. 홀딩 상태 연속 대기 약 1.8시간. 시험·모의대회 하루 사용에 충분. NiMH 사용 중 전압 모니터링(추가기능 ③, ADC 분압)은 포크 방식과 동일.

### 7.2 시제품 측정 절차서 (작업 2-5, 사용자) — 모든 측정은 7.2V 팩으로, 홈잉 후

**A. 반복정밀도 @R=386 (펜-종이)**
1. 포크 포켓 중심에 볼펜을 수직으로 고정(스프링으로 종이에 가볍게 닿음, 펜 끝 = 포켓 중심). 종이를 판 위에 테이프로 평평하게 고정, 높이는 포켓 높이.
2. 목표 (θ=73.4°, R=386)로 이동해 Z로 펜을 내려 점을 찍고, 올린 후 운반 위치(θ=180°, R_C=200)로 갔다가 같은 목표로 복귀 — **이 사이클 10회**. 접근 방향은 (a) 항상 같은 방향(한 방향 규칙), (b) 번갈아 반대 방향으로 두 번 반복(20점).
3. 종이를 떼어 캘리퍼로 점들의 최대 폭을 **반경 방향(펜 점이 이루는 방향)과 접선 방향**으로 읽고, 평균 위치에서 각 점의 편차의 표준편차를 계산. 보고: `max−min`(mm), σ, 방식 (a)/(b).
4. 같은 절차를 (θ=101.5°, R=326.5)에서 1세트 더. 판정 기준 ±5mm는 `(max−min)/2 ≤ 5`로 해석.

**B. 팔끝 처짐**: 정지 상태에서 포크 아랫면 높이를 캘리퍼 깊이 로드(또는 높이 게이지·수평 자)로 R_w=100, 250, 322에서 측정. CD(16g)와 포크 장착 상태·미장착 상태를 비교. 처짐 = h(R_w=100) − h(R_w=322). 기준 3mm 이하.

**C. 질량**: 주방 저울(±1g)로 하위 조립체별(차체 / Z 고정부 / 승강대 / 팔 전체 / 포크) 질량을 측정해 §3.3 표에 기입, 합계 확인.

**D. 전원**: 멀티미터 min-hold로 모터 팩 전압을 측정하며 3축 동시 이동 + DC 모터 풀파워를 3회. 최저 전압 기록. Mega 리셋 발생 여부 관찰(리셋 0회).

**E. 방향 추정**: 연습 경기장 중단 행선을 일부러 0, ±1°, ±2°로 틀어 통과시켜 추정값 ψ를 시리얼로 출력(각 10회) → 실제 각도와 비교. 목표 오차 ≤0.6°.

**F. CD 사이클**: 1-3 더미 베이스에 실제 CD로 한 행 전체 사이클을 10회 — 성공(안착 후 베이스·CD 이동 <3mm) 횟수.
