## 1. 결론 — "단일 승강축 와이드 C-링 포크 + 넥 접촉 정지"

| 하위 시스템 | 채택 | 출처 아이디어 |
|---|---|---|
| 승강 구동 | 스테퍼 SF2421 + **T8 리드스크류(리드 8mm)** + Ø8 가이드봉 2개 + LM8UU, 행정 60mm | A01 (D04 대안) |
| 원점·초기화 | 하단 리밋 스위치 원점 잡기 (추가기능 ④), 상단 리밋 = 과주행 보호 | A01, B 결합메모 |
| 엔드이펙터 | **U 내폭 78mm** 포크 + 8° 원추 시트 + C-링 림 턱(앞·뒤 호) — PETG | D01(내폭), B02(원추), B03(림) |
| 깊이 정렬 | 정지선 이벤트 → 저속 전진 → **포크 U 바닥 저작동력 레버 스위치가 넥(Ø50)에 닿으면 정지** | D13 |
| 웨이퍼 감지 | 캐리지에 **상향 IR**(GP2Y0A41), 포크 윗면 45mm 아래 → CD 있음 55mm / 없음 >300mm | D17, B19 |
| 경로 | 단방향 + 제자리 회전. 180°는 후퇴 후, **항상 자기 구역 안쪽(남쪽)으로 휘두름** | C 골격, D 함정7 |
| 동작 모터 | **1개**(스테퍼). 2개는 예비 | — |

탈락한 유력안과 이유:
- **C24 스크류-래칫 포탑**(스핀 제거, −6s): 도그클러치 시제품 검증이 필요해 4주 일정에서 위험. 예선 시간 여유(약 55s)가 커서 6s 절약의 가치가 낮다. → v2 창의성 개선 후보
- **C23 평행링크 리치-리프트**(접힌 채 회전 → 구역 침범 해결): 링크 핀 유격, 각도-높이 비선형. §3의 경로 규칙으로 침범을 해결하므로 보류. → 모의대회에서 침범 판정 문제가 생기면 1순위 교체안
- **C09 2단 tine + 캠**: 175행에서 위층 tine–CD 간격 15mm가 빠듯하고 캠 반복 정밀도 검증 필요
- **C16 상승-협지 패드**: 패드를 캐리지에 달면 CD와 함께 움직여 협지가 안 되고, 프레임에 달면 행마다 협지 높이가 다르다. 림 턱 + 원추 시트로 수평 이탈을 막고 회전 각가속도를 제한(§4)하는 쪽이 단순
- **D01 편심캠(타미야)**: 행정 고정이라 175/200 두 높이의 "아래·운반" 4위치를 만들 수 없음
- **서보 단독안(A05, A14, A18, A23)**: 추가기능 ④(센서 기반 초기화) 불인정

## 2. 아레나가 놓친 기하 제약 두 가지 (선정 과정에서 발견)

### 2.1 라인센서가 베이스 하단 원기둥 안으로 들어가는 문제
픽 위치에서 포켓 중심 = 기둥 중심. 하단 원기둥(Ø100)은 바닥에서 중심 반경 50mm를 차지한다. 바닥 가까이 있는 라인센서와 차체 앞면은 기둥 중심에서 **55mm 이상** 떨어져야 한다.
→ **센서 → 포켓 중심 ≥ 55mm** (C 관점의 "40mm 이내" 규칙은 차체 앞면 기준이며, 센서 위치에는 이 하한이 추가로 걸린다)

### 2.2 상단 행 교차점에서 상대 구역 침범
본선 그림에서 두 팀의 구역은 베이스 쪽이 서로 마주 보고, 상단 행(y=130)은 경계선에서 130mm 떨어져 있다. 고정 포크 로봇의 포크 끝은 바퀴축에서 157mm 앞에 있다(v1.1). 북쪽을 보고 상단 교차점에 도착해 축을 교차점 중심(y=130)에 두면, 포크 끝이 경계 밖으로 약 27mm 나간다.
→ §3의 상단 행 전용 규칙으로 해결한다.

**상단 행 규칙**
1. 상단 교차점 규칙 (v1.1에서 재계산):
   - 중단 교차점을 지나면 **저속**으로 상단 교차점에 접근한다. 이벤트(약 6mm 지연) + 제동 오버슈트로 센서가 라인 위 y≈124까지 들어가면 축은 y≈149, 포크 끝은 y≈−8로 **경계를 넘는다** → 이벤트 후 **15mm 후진**(`TOP_BACKOFF_MM`)해 축 y≈162, 포크 끝 y≈+5로 맞춘다.
   - 이 위치에서 센서는 라인보다 남쪽에 있고, 센서가 라인 위에 머무는 회전각은 26°뿐이다(25·cosθ ≥ 22.5). 그래서 라인 확인 회전은 쓸 수 없다 → **시간 기반 90° 제자리 회전**(라인 확인 없음). 포크 끝 궤적은 축 중심 반경 157 원이고 북쪽 최대점은 회전 시작점(y≈+5)이므로 침범하지 않는다.
   - 회전 후 센서는 라인 남쪽 약 22mm, 라인과 평행 → **라인 쪽(북쪽)으로 약 15° 편향 전진**(`A_ACQUIRE`)하다가 어느 채널이든 흑이면 PD 추종으로 전환(약 90mm 이동 후 획득, 정지선까지 남은 약 180mm에서 방향 수렴).
   — 펌웨어: 상단 행 전용 동작 `A_FWD(−TOP_BACKOFF_MM)` → `A_TURN_TIMED` → `A_ACQUIRE`. 모의경기장에서 각도·편향·시간 실측
2. 상단 행에서 180° 회전은 반드시 남쪽 경유: 서→동은 좌회전(W→S→E), 동→서는 우회전(E→S→W).
3. 회전 전 포크 높이는 기둥 윗면 + 5 이상으로 올리고, 후퇴는 100mm로 한다. 포크 끝 반경 157 < 축–넥 거리(후퇴 후 92+100) − 넥 반경 25 = 167 (여유 10).

## 4. 동작 시퀀스 (한 행)

1. 교차점 → (상단 행 규칙) 회전 → 라인추종(기둥 근처 감속) → **정지선 이벤트**
2. 승강: 아래 높이(기둥 윗면 − 10)로 이동해 대기
3. **크리프**: 저속 전진하다 넥 접촉 스위치가 눌리면 정지(시간 초과 1.5s = 고장). 크리프 시간을 기록
4. 감지: 상향 IR → 있음/없음
5. 있음: 운반 높이(기둥 윗면 + 12)로 올림 → 후퇴 100 → 남쪽 경유 180° 회전(각가속도 램프 ≥ 0.3s) → 교차점 통과 → 맞은편 정지선 → **3에서 기록한 크리프 시간만큼** 전진(넥 스위치는 포크가 기둥 위에 있어 안 눌림) → 아래 높이로 내려 놓기 → 후퇴 100 → 회전 → 교차점
6. 없음: 포크를 기둥 윗면 + 5로 올림 → 후퇴 100 → 180° → 맞은편에서 3~5를 반복한 뒤 반대 방향으로 운반
