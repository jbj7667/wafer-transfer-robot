# 부품 명세서 (BOM) — 확정안 v1

- 기준일: **2026-10-26** (가격 기준일). 기구는 `mechanism.md`(단일 승강축 와이드 C-링 포크 + 넥 접촉 정지)를 따른다.
- 규정: 사비 구매 부품 합계 **120,000원 이하**, 영수증 전부 첨부. 허위 기재는 실격.

> **가격 신뢰도 주의 (필독)**
> 2026-10-26에 웹검색(standard)으로 국내 쇼핑몰(디바이스마트·엘레파츠·아이씨뱅큐·11번가·쿠팡·알리 KR) 가격을 조회했으나, 검색 도구가 해당 쇼핑몰 상품 페이지의 원화 가격을 거의 반환하지 못했다.
> 확인된 국내 실가격 단서는 쿠팡의 리밋 스위치 개당 약 500원(배송비 3,000원 별도, 모델 미특정), PETG 1kg 약 8,800원(표시 정가 25,000원, 날짜 불확실) 두 건뿐이다.
> 따라서 아래 단가는 **추정치(보수적으로 높게 잡음)**이다. 주문 시점에 URL(검색 페이지)에서 실가격을 확인해 `확정가` 칸을 채우고 합계를 다시 계산한다. 합계가 추정치로도 한도의 약 69%이므로 실가격 편차를 흡수한다.
