# 최종 완료 보고서 아웃라인 (제출: 2026-12-08, HWP)

학부 "보고서 작성에 필요한 Diagram" 자료의 필수 항목과 부록 항목을 모두 포함하도록 구성했다. 사진은 직접 촬영한 것만 쓴다(학과 자료 사진 사용 시 감점).

## 본문

1. **개요**
   1.1 과제와 대회 소개(웨이퍼 이송로봇 부문, 예선·본선 방식)
   1.2 팀 구성과 역할(1인: 기구·회로·프로그램·발표 전담)
   1.3 목표: 예선 4점 90초 이내, 추가기능 5/5
2. **요구사항 분석**
   2.1 경기장·베이스·웨이퍼 기하 (`docs/requirements.md`)
   2.2 제약 조건 표(크기·모터·센서·전원·예산·가공)
   2.3 **목적계통도** (필수) — 최상위 목적 "웨이퍼 3장을 120초 안에 정확히 이송" → 정확성·속도·신뢰성·규정 준수·가점
   2.4 **기능계통도** (필수) — 주행(라인추종·교차 인식·회전) / 이송(정렬·집기·운반·놓기) / 판단(웨이퍼 감지·경로 계획) / 인터페이스(출발·전압·LED)
3. **선행기술조사서** (필수)
   3.1 산업용 웨이퍼 이송 로봇의 엔드이펙터(패들·엣지그립·진공)와 본 설계의 대응
   3.2 라인트레이서 제어(PD, 교차 카운팅)
   3.3 타 팀·작년 대회 메커니즘 비교와 개선점(랙 유격, CD 이탈, 리셋) — 실명 없이 유형으로
4. **개념 설계와 메커니즘 선정**
   4.1 100안 아레나 방법(4관점 × 25안)과 평가 기준·가중치
   4.2 상위안 비교표와 최종안 선정 근거 (`docs/design/mechanism.md`)
   4.3 아레나가 놓친 기하 제약 2가지와 해결
5. **시스템 설계**
   5.1 **시스템구성도** (필수) (`wiring.md` 블록도)
   5.2 블록구성도: 전원·제어·구동·센서·통신
   5.3 기구 설계: **설명용 기구조립도** (필수), 주요 치수, 출력 방향·재질·중량
   5.4 회로 설계: 전원 분리, 분압, 노이즈 대책, 드라이버 전류 설정
   5.5 소프트웨어: **순서도(알고리즘·동작)** (필수), 상태머신, 타이머·인터럽트 구조, 프로토콜
   5.6 스마트폰 앱 화면과 블록 설계
6. **제작**
   6.1 출력·조립 과정 사진(부분별 명칭 표기) (필수: 구현 작품 실제 사진)
   6.2 배선 사진
   6.3 비용 집행 내역과 영수증 요약(12만 원 한도 대비)
7. **시험과 개선**
   7.1 단위 시험: 라인센서 튜닝(전압·높이·기울기·차광), 승강 정밀도, 넥 접촉, IR 감지
   7.2 통합 시험: 연습장·모의대회 1·2 결과(성공률, 시간)
   7.3 문제와 해결 기록(원인 분석 → 대책 → 재시험)
8. **경진대회 결과와 고찰**
   8.1 예선·본선 기록
   8.2 추가기능 평가 결과
   8.3 잘된 점·아쉬운 점·향후 개선(포탑형 C24, 평행링크 C23 등)
9. **결론**

## 부록 (필수 첨부)

- A. 기구 상세 부품도·조립도 — 치수 표시 (Fusion 도면)
- B. 회로도·배선도 — 부품명·전원 전압·극성·핀번호·모든 배선 연결 (`wiring.md` 기반)
- C. 사용 전기·전자 부품 핀배치도·내부 구성도 (데이터시트 발췌: Mega 2560, L298, DRV8834, HC-SR04, GP2Y0A41, HM-10, 라인센서)
- D. 소스코드 목록과 주요 부분 (`firmware/`), 앱 블록 캡처
- E. 영수증 원본 스캔과 필라멘트 g단가 산출 근거
- F. 동영상 링크(제작 과정·결과, YouTube)
