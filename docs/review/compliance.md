## 3. 추가 기능 5점

| # | 요건 | 구현 | 판정 |
|---|---|---|---|
| F1 | 지급 BLE 모듈 + **전용 앱**으로 출발(터미널 앱 불인정) | App Inventor 앱 START → "S" → IDLE에서만 RUN | ✅ (앱 빌드·실기 시험 남음) |
| F2 | 로봇 부착 푸시 스위치로 출발 | D19 버튼, 1kHz 디바운스 | ✅ |
| F3 | 스마트폰 전압 모니터링(**전용 앱**) | 분압 1/3 → A2/A3 → "V,..." 2Hz → 앱 표시·경고색 | ✅ |
| F4 | 전원 On 시 **센서로** 자체 초기화. RC서보 단순 구동·초기화 불필요 구조 불인정 | 스테퍼 승강축을 하단 리밋 스위치로 원점 잡기(빠른 탐색 → 후퇴 → 느린 재탐색) | ⚠️ 리밋 스위치를 "센서"로 인정하는지 확인 권장. 보강안: 원점 잡기 후 상향 IR로 포크 위 비어 있음 확인, 라인센서 자가점검을 함께 표시 |
| F5 | 외관 LED, 이동 중 Off, 시작·도착 구역에서 초당 4회 **계속** 점멸 | Timer1 125ms 토글. IDLE·HOMING·ARRIVED 점멸, RUN 소등 | ✅ |

※ 추가기능은 예선에서 평가하고, 본선에서 동작하지 않으면 점수가 취소된다 → 본선 전 체크리스트에 F1~F5 시연 포함.

## 4. 불필요한 변경·규정 이탈 점검

| 항목 | 내용 | 판정 |
|---|---|---|
| 모터드라이버 | 지급 L298 유지. TB6612 교체는 Q&A 확인 전까지 하지 않음 | ✅ 변경 없음 |
| 스테퍼 드라이버 | A4988 → DRV8834: 학과가 전압 부족으로 교체 지급한 부품 | ✅ |
| 엔코더 | 사용 안 함(센서 지급품 규정) | ✅ |
| 원격 조작 | 주행 중 앱 명령 무시 | ✅ |
| 처음 요약과 다른 결정 | 아크릴 → 개인 3D 프린팅 | ⚠️ R13과 동일 항목 |

**결론**: 위반(❌) 없음. 조건부(⚠️) 6건은 모두 **실측 또는 지도교수 확인**으로 닫힌다. 가장 먼저 처리할 것은 R13(3D 프린팅 허용)이다.

## 5. Fusion v1.1b 실측 (2026-10-27, `cad/model/README.md`, 클라우드 `Default Project/wafer_robot_v1_1`)

모델은 단순화(상자·원기둥)했고 치수·배치는 `cad/params.md` v1.1b와 같다. 간섭 해석은 Fusion 간섭 검사 + 좌표 계산으로 했다.

| 항목 | 기준 | 실측 | 판정 |
|---|---|---|---|
| 출발 자세 외곽 (L×W×H) | ≤ 250×250×250 | **250 × 210 × 245** (X −93~157, Y ±105, Z 0~245) | ✅ (v1.1b 길이 여유 0 → **v1.1c 후면 −92로 길이 249**, 출력 공차 1mm 확보) |
| Z<100, |Y|≤50 부품 최전방 | ≤ +40 (하단 원기둥 시작 +42) | 하판 +40, 라인센서 +37, 스테퍼 +36 | ✅ |
| 픽 접근(포크 윗면 Z155) 로봇–베이스 간섭 | 0 | 0 | ✅ |
| 200행 픽(포크 Z190) 로봇–베이스·CD 간섭 | 0 | 0 (넥 횡 여유 14) | ✅ |
| 운반(포크 Z212) 캐리지·마스트–들린 CD 간섭 | 0 | 0 | ✅ |
| 캐리지 상단–상단 블록 | > 0 | 4 | ✅ |
| 리드스크류 너트–스크류 끝 | > 0 | v1.1b 0 → **v1.1c 너트 하향 장착으로 10** | ✅ (모델 반영은 다음 수정 때) |
| 로봇 내부 간섭 | 0 | 0 (면 접촉만) | ✅ |
| 출력 부품 총중량(추정) | — | 약 424 g (PLA 285 + PETG 139), 낭비 포함 약 490 g ≈ 9,800원 | 예산 반영 |

모델링 과정에서 발견해 고친 설계 오류(문서 단계에서 놓친 것): CD–마스트 겹침, 스테퍼의 하단 원기둥 침범, 라인센서 PCB 2mm 겹침, 마스트 높이 1mm 초과, 리드스크류 길이(150 → 100), 배터리–스테퍼 겹침(배터리 가로 배치), 상단 행 회전 시 센서 이탈과 오버슈트 침범(후진 + 시간 회전 + 편향 진입). 상세: `cad/params.md` §7, `mechanism.md` §3.
