# 브레인스토머 A — 승강·구동 기구학 관점

## 공통 기하 (모든 아이디어에 적용한 가정)
- CD 밑면 높이 H = 175 또는 200. 포크 윗면 필요 위치: 진입 H−8 → 들어올림 H+10 → 내려놓기 H−8. 즉 Z 위치 4개(167/185/192/210), **필요 스트로크 ≈ 43mm, 여유 포함 60mm(160~220)**. 220 < 250 이므로 시작 크기와 충돌 없음.
- 포크: U자, 내측 간격 70mm(기둥 Ø50 → 좌우 각 10mm 여유), 갈래 폭 15mm(반경 35~50 위치에서 CD 지지, CD 반경 60). 갈래 길이 130mm.
- 하단 원기둥 Ø100 윗면이 z=100 이므로 포크(z≥160)와 간섭 없음. 몸체 앞끝은 베이스 중심에서 55mm 이상 떨어져야 함 → 정지선(중심-100) 기준 몸체 앞끝 ≤ +45mm.
- **포크 U 중심을 라인센서보다 정확히 100mm 앞에 두면 "정지선 검출 = 포크 정렬"이 되어 별도 리치 축이 필요 없다.** 리치 축 아이디어는 이 오차(±5)를 줄이거나 몸체 충돌을 피하려는 대안.
- 내려놓기 허용: CD가 Ø50 위에 남으려면 중심 편차 < 약 20mm.
- 타미야 H.E. 6단 기어박스 감속비는 대략 11.6 / 18.9 / 38.2 / 64.8 / 115 / 344:1 범위(정확 값은 실측 필요), 5V 부근에서 38:1 단 출력 ≈ 150~200rpm 추정.
- SF2421 스테퍼 200스텝/rev, DRV8834 1/8 마이크로스텝 시 1600펄스/rev.

## 내 관점 상위 5개

1. **A01 스테퍼 + T8 리드스크류 (+ "센서-포크 100mm 오프셋" 고정 리치)**
   셀프락이라 전원/진동에도 높이가 안 변하고, 하단 리밋 호밍으로 자체 초기화 점수를 확실히 받는다. 60mm/1.2s면 3회 왕복 기준 사이클 손실이 약 7s로 120s 예선에서 충분하다. 범용 부품(T8 300mm, LM8UU, 봉) 합계 약 2만원이라 1인 4주 일정에 가장 안전하다.

2. **A21 배럴 캠 승강 (A01 대안/업그레이드)**
   체류 구간 덕분에 스텝 탈조가 생겨도 높이 오차가 0에 가깝고 1회전 0.5s로 빠르다. 출력 난도가 있지만 Bambu A1에서 세로 분할 출력하면 2~3회 반복으로 확보 가능하다. 시간이 남을 때만 시도한다.

3. **A22 플로팅 V 센터링 포크 (어떤 승강축과도 결합)**
   정렬 허용오차(가중치 20)를 좌우 ±10 → ±18로 늘리는 유일한 수동 기구다. 라인추종 횡오차 ±5~8을 여유 있게 흡수한다. 베이스가 고정되지 않았으므로 스프링력 0.2N 이하, U 바닥 리밋은 15gf급 마이크로스위치를 쓴다.

4. **A24 관람차형 180° 스윙**
   타팀의 "회전 시 CD 이탈"은 로봇 선회 때문이다. 포크가 앞→뒤로 넘어가면 로봇은 행 라인 위에서 직진·후진만 하면 되고, 라인센서를 차체 중앙에 두면 양방향 추종이 대칭이 된다. 다만 난이도가 4라서 2주차까지 A01이 완성됐을 때만 2차 후보로 둔다.

5. **A03 타미야 + T8 + 높이 스위치**
   스테퍼를 주행 보조나 다른 축(A24 회전 등)에 써야 할 때, 승강을 DC로 돌리고 슬롯을 아끼는 방안이다. T8의 셀프락 덕분에 DC 오버런이 ±1.5mm로 작고, 스위치 4개로 행 높이를 기계적으로 정의하므로 소프트웨어 실수에 강하다.

## 다른 관점과 결합 메모
- **A01 + A22 + "센서-포크 100mm 오프셋"**: 정지선 검출 순간이 곧 포크 정렬이 되고(리치 축 0개), 플로팅이 횡오차를 흡수한다. 모터 1개만 써서 나머지 2슬롯이 남는다. 추천 기본안.
- **A24/A25 ↔ 주행·경로 관점**: 선회 없이 왕복하는 경로 전략과 짝을 이룬다. 단, 라인센서가 1개뿐이므로 센서를 차체 중심(바퀴축 근처)에 두는 레이아웃과 반드시 함께 검토해야 한다.
- **A09/A19(리치 보정) ↔ 센서 관점**: IR이 Ø50 곡면을 측정하면 노이즈가 크다. 초음파는 근거리 하한(약 20mm) 문제가 있다. 정지선 기반 고정 오프셋이 더 신뢰성 있으므로 리치 축은 정지선 오차가 실측 ±8을 넘을 때만 쓴다.
- **A16 쐐기 조 ↔ 그리퍼/핸들링 관점**: "들기"를 Z 축에서 분리하면 승강축은 2위치(175/200)면 충분하므로 서보 토글(A23)과 리밋 1개로 단순화할 수 있다.
- **전기 관점 공통**: 스테퍼 상시 통전(홀딩)은 7.2V 팩을 소모하므로 리드스크류(셀프락)계는 이동 후 DRV8834 SLEEP으로 전류를 끊을 수 있다. 벨트·랙계(A02, A07)는 그러면 안 된다.
