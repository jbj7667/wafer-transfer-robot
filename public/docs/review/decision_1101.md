# 11/01 판정: 트랙 1(포크 + 승강축 1개) vs 트랙 2(팔 θ-R-Z)

작성 2026-10-30. 기준은 `PLAN_v2.md` §2.3. **하나라도 미달이면 트랙 1로 확정**한다. 이 문서는 사전 판단 + 사용자 측정값을 채우는 양식이다. 측정 후 칸을 채우고 최종 판정을 적는다.

## 0. 사전 판단 (측정 전, 2026-10-30 시점): **트랙 1 확정을 권고**
| 근거 | 내용 |
|---|---|
| 팔 방식 해석 결과 | `arm_option.md`: 접힘이 최대 쟁점(L=205는 축을 68 mm 비껴야 여유 2 mm, L=180은 여유 거의 0 → 조건부 통과), 헤딩 2° 오차 = 팔끝 13.5 mm(U 허용 ±14의 96 %), 벨트 슬랙으로 반복정밀도 1σ 3.3 mm(경계), 질량 팔 2.8 kg / 포크 2.0 kg |
| 동작 모터 상한 | 팔은 스테퍼 3개로 상한 3개를 전부 사용(예비 0), 2개는 학과 대여 필요 |
| 구매 조건 | 사용자 결정: **신규 구매 없음**(동아리 보유 자재로 제작). 팔 방식은 2GT-6 벨트·608 베어링 등 구매 또는 보유 확인이 필요 |
| 진행 상태 | 트랙 1은 승강부 전부 출력 설계·조립 검증 완료(`public/cad/assembly/interference.md`: 정적 간섭 0, 출발 크기 X −92~157 / Y 210 / Z 245, 앞 전복 한계 0.28 g) |
| 일정 | 11/10 모의대회 1에서 예선 완주가 목표 — 두 트랙 병행은 출력·조립 시간이 모자람 |

→ 아래 측정값이 모두 합격이면 팔 방식을 재검토하되, **기본 판정은 트랙 1**이다.

## 2. 트랙 1 현재 수치 (비교용)
- 질량: 출력 부품 약 315 g(PLA 94 / PETG 209 / TPU 12), 총질량 약 1.49 kg(기성품 질량 가정 포함, 배선·볼트 제외) — 조립 후 저울로 실측해 이 표에 갱신.
- COM: X −19.8, Z 69~73(f=155~227). 앞 전복 한계 2.7~2.8 m/s²(0.27~0.29 g) → 제동은 2 m/s² 이하(`config.h`의 `BRAKE_MS`, `BRAKE_DUTY_START`로 조정).
- 승강: 리드 8 mm/rev, 20 mm/s 한도(`LIFT_RATE_MAX` 500 step/s), 포크 이동 72 mm ≈ 3.6 s.
- 시간 예산: 예선 90 s 이내 목표(`PLAN.md`).

## 3. 사용자가 측정해서 채울 것 (팔 벤치를 출력한 경우만)
- 절차서: `public/docs/design/arm_bench.md` §측정(386 mm 반복 정밀도: 종이에 펜 자국 10회, 팔끝 처짐: 16 g 추를 달고 변화량, 질량: 저울).
- 벤치 출력 부품 17종(약 12.4 h)은 `public/cad/arm_bench/`. 팔 방식을 진행하지 않기로 하면 이 절은 생략하고 판정을 트랙 1로 확정한다.
