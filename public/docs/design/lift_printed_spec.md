# 승강부 v2 (전부 출력) — 인터페이스 사양

작성 2026-10-29. 목적: 구매 없이 승강부를 3D 출력만으로 구성한다(스테퍼·스위치·볼트·너트만 기성품). 모든 좌표는 로봇 좌표(+X 전진, +Y 좌, +Z 위, mm, 원점 = 바퀴 접지점 중점 바닥). 부품 파일은 `public/cad/print/`에 두고 **출력 자세**로 내보낸다. 각 부품은 출력 자세 → 로봇 좌표 4×4 변환을 `placement_<에이전트>.json`에 기록한다(조립용).

## 고정 사실 (변경 금지)
- 하판 P01: Z 52~56. 스테퍼 SF2421 42×42×40, 중심 (15, 0), Z 56~96, 축(Ø5) 위쪽, P08 칼라·판 그대로 사용(수정 없음).
- 상판 P02: Z 100~103. 마스트 관통 구멍: Ø20 @ (15,0), Ø9 @ (15, ±30) — 레일/스크류가 통과.
- 기존 마스트 하부 블록 자리: X 3~27, Y 22~38, Z 56~72 (중심 (15, ±30)). 하판 체결 구멍은 P01의 (6,25), (6,35), (6,−25), (6,−35) 와 (14,±54) 등 기존 패턴 유지.
- 상부 블록 자리: X 0~30, Y ±38, Z 232~245. 아랫면 Z=232 가 캐리지의 기계적 정지.
- 포크 윗면 높이 f: 원점 155, 소프트웨어 상한 215, 기계적 상한 227. 즉 포크 이동 72 mm.
- 포크(P13) 포켓 중심 (92, 0), U 내폭 78, 8° 원추 시트, 림 Ø123 — 형상 변경 없음. 포크 루트는 캐리지 윗면에 얹혀 볼트 체결한다(아래).
- 모터 SF2421 축 Ø5(둥근 축, 플랫 유무 불명 — 커플러는 Ø5.1 구멍 + M3 세트스크류 2개(90° 간격)).
- 기성품은 M3 볼트·너트·와셔(여러 길이), 스테퍼 SF2421, 마이크로 스위치(치수 미정, 아래 가정)뿐. **인서트 없음** → 인서트 구멍은 M3 자체탭(Ø2.8 구멍, 깊이 ≥8) 또는 관통 Ø3.4 + 너트 포켓(AF 5.7, 깊이 2.6)으로 한다.

## 산출물 이름 (출력 폴더 `public/cad/print/`)

- 레일: `P22_rail.stl`(2개 출력)
- 마스트: `P09_mast_lower_v2_L.stl`, `P09_mast_lower_v2_R.stl`, `P10_mast_upper_v2.stl`
- 캐리지: `P12_carriage_v2.stl`
- 포크: `P13_fork_v2.stl`
- 리밋 칼라: `P11_limit_collar_v2.stl`(원점용 1개; 상한은 장착하지 않음)

## 공통 규칙
- Python(trimesh + shapely + manifold3d)으로 직접 생성: `from v12_parts import cyl, union, diff, extrude, save` (같은 폴더). 저장은 반드시 `save()`(닫힌 형상 검증 포함).
- 스크립트는 `public/cad/print/lift_<이름>.py`, 실행은 워크트리 루트에서 `python public/cad/print/lift_<이름>.py`.
- git 명령은 한 번에 하나씩 단순하게(복합 명령은 격리 가드가 막음). **커밋은 메인이 한다. 에이전트는 커밋하지 않는다.**
- 각 부품: 닫힌 형상, 출력 자세(서포트 최소), 간섭 검사(이웃 부품과 수치), 질량 추정, 출력 설명을 스크립트 끝에서 출력한다.
