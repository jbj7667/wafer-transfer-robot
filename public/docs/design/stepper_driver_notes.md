# 승강 스테퍼 드라이버 메모 (DRV8825 임시 시험 / DRV8834 대회용)

작성 2026-10-31. 핀·전원 상세는 `wiring.md`, 펌웨어는 `public/firmware/wafer_robot/lift.cpp`·`config.h`.

## 1. 핵심 주의
- **현재 펌웨어는 풀스텝 기준**이다(`LIFT_STEPS_PER_MM` = 25 = 200 step/rev ÷ 리드 8 mm). 따라서 드라이버의 **M0·M1(·M2)은 모두 LOW(GND 또는 내부 풀다운으로 열어 둠)** 로 풀스텝에 맞춘다. 마이크로스텝(1/8 등)으로 바꾸면 `LIFT_STEPS_PER_MM`, `LIFT_RATE_MAX`, `LIFT_RATE_MIN`, `LIFT_ACCEL`, `HOME_RATE_*`를 같은 배수로 곱해야 한다(이전에 안내한 'M0=H, M1=H, M2=L(1/8)'은 현 펌웨어와 맞지 않음).
- 최고 속도는 500 step/s(150 rpm = 20 mm/s, 풀스텝). 7.2 V 팩에서 SF2421의 풀아웃 토크는 높은 속도에서 급감한다(레드팀).

## 2. 드라이버별
| | DRV8825(보유, 임시) | DRV8834(규정 교체 지급, 대회용) |
|---|---|---|
| 모터 전원 VMOT | **최소 8.2 V** — 7.2 V NiMH(부하 시 7.0~7.4 V)에서는 UVLO로 꺼질 수 있음 → 시험은 충전 직후 팩 또는 벤치 전원 8.4 V 이상 | 2.5~10.8 V → 7.2 V 정상 |
| 마이크로스텝 핀 | M0 M1 M2 (풀스텝 = 전부 LOW) | M0 M1 (3상태: 풀스텝 = M0 LOW, M1 LOW — 캐리어 표 확인) |
| 전류 설정 | 한계 전류 ≈ VREF × 2 (감지저항 0.100 Ω 보드; 보드의 저항 표기 R100 확인 **[확인필요]**) | `wiring.md` §전류 설정 참고(보드 감지저항 확인 **[확인필요]**) |
| SLEEP/RESET | nSLEEP·nRESET을 HIGH로(D38 = nSLEEP, nRESET은 nSLEEP과 묶거나 5 V) | nSLEEP = D38 |

## 3. 전류 설정 (SF2421 추정 정격 1 A, 3.6 Ω/상 — 실측 필요)
- 목표 약 0.7 A/상(발열·전원 여유). DRV8825(0.100 Ω)이면 VREF ≈ 0.35 V(0.7 A ÷ 2).
- 전원이 7.2 V일 때 이론 최대 전류는 7.2 V ÷ 3.6 Ω = 2 A라 한계값에 도달하며, 이 한계가 걸리면 토크는 인덕턴스로 제한된다.
- 설정 순서: 모터 선을 뽑은 상태에서 VREF를 맞춘 뒤 → 전원 끄고 모터 연결 → 시험. **모터가 전원 켠 상태에서 선을 뽑거나 꽂지 말 것**(드라이버 손상).
- 100 µF 전해 콘덴서를 VMOT–GND 가까이(5 cm 이내) 달고, 로직 GND와 모터 GND를 한 점에서 공통으로 한다.

## 4. 시험 순서
1. `public/firmware/tests/t03_stepper_homing`로 방향·원점·리밋 스위치 확인(DIR이 반대면 코일 한 쌍의 선을 바꾼다).
2. 손으로 캐리지가 부드럽게 오르내리는지 확인(출력 나사 마찰). 뻑뻑하면 `P21t_nut_test` 결과를 보고 clearance를 올려 재생성.
3. 속도를 200 → 500 step/s로 올리며 탈조(소리·정지) 지점을 기록 → `LIFT_RATE_MAX`를 그 80 % 이하로.
4. 대회용 DRV8834를 받으면 같은 순서로 반복.
