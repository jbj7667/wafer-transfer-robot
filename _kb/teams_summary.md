출처는 `주제 별 학습 활동` 아래 2~7주차 자료 약 40개입니다. A04, C04, 텔레토비, 일잘하는프로 자료는 이미지뿐이라 텍스트가 거의 없습니다. 5~7주차 자료는 대부분 사진과 영상이라, 여기 적은 내용은 텍스트와 일부 이미지를 직접 확인한 결과입니다. 추정은 (추정)으로 표시했습니다.

## 2. 팀 간 공통 패턴

- **기구**: 지게차형 전면 포크가 가장 많습니다(A02, A07, A08, B02, B06, C01, DTS, 텔레토비 등). 확인된 포크 형상은 **U자·반원 컷아웃 판**으로, CD 중앙의 받침대 기둥을 피해 CD 밑면을 받치는 방식입니다(A02 명시, A07·B02 도면). 그 밖에는 틸트 방식(B04, C06), 크랭크·서보(B08), 집게(C02, WaferWay), 회전 포탑(B05), 관통 컨베이어(B03)가 있습니다.
- **승강 구동**: 타미야 + 랙&피니언 또는 웜이 가장 흔합니다(A07, B05, B06, 기갑대, 일취월장). 스테퍼 + 슬라이더·리드스크류가 그다음입니다(A02, B02, B03, 임전이양). 높이 차가 25mm뿐이라 대부분 리프트 높이 2위치로 대응합니다. 원점은 리밋·홈 스위치로 잡습니다(A02, B03, B02).
- **표준 구성**: Mega + IO 실드, L298 2개(주행과 타미야 분리) 또는 L298 + A4988, AA×6 배터리 2팩을 스위치로 분리하고 GND는 공통. 거의 모든 팀이 HM-10 BLE와 상태 LED를 둡니다.
- **센서**: 라인센서(1~5ch), 초음파 또는 IR 거리(CD 유무 확인, 기둥 거리로 정지). 본선의 CD 좌/우 판정은 거리센서로 합니다(A02).
- **5~7주차에 실제로 진행된 것**: 단위 테스트(DC, 타미야, 라인, IR, 초음파: A07, B02), 아크릴 레이저컷 섀시 조립(A07 사진: 2층 판, 하단에 배터리·DC, 상단에 Mega와 L298×2). 7주차 텍스트에 완주 성공 보고는 없습니다.
- **반복된 문제**:
  - 랙·기어 강성 부족과 진동으로 인한 유격(A07, 6·7주)
  - 기구 공간 간섭(A07의 타미야 공간, B10의 CD 픽업 간섭)
  - IR 센서 고장·불안정 → 초음파로 교체(C03)
  - 라인센서 장착 높이에 따른 인식 차이(B09, 늙크크)
  - 회전 시 CD 이탈 → 고무·가이드 턱, 들고 나서 후진한 뒤 회전(A02, B05, C02)
  - 모터 노이즈로 Mega 리셋 → 전원 분리(공통 지적)
  - 2025년 회전 포탑 팀의 기구 틀어짐(B03 분석)

## 3. 규정·경기장 관련 언급 (팀 자료 기준, 공식 문서로 재확인 필요)

- 시작 크기 250×250×250mm 이하. 베이스 높이 175/200mm. **높이 차는 25mm**입니다.
- 제한시간: **예선 120초 / 본선 150초**(A02). 여러 팀이 "120초"로 적었습니다.
- 예선: CD 3개가 모두 왼쪽에 있고 오른쪽으로 옮깁니다. 본선: 각 단의 CD가 좌/우 무작위로 놓이고 반대쪽으로 옮깁니다. 3개를 옮긴 뒤 출발·종료선으로 복귀해야 완주입니다(A02).
- 사람 개입 없는 완전 자율. 주행 DC 2개(지급품) + 비구동 모터(타미야, 스테퍼, RC 서보) 합계 3개 이하. AA×6 직렬, 제어·모터 전원 분리 가능, 각각 스위치 설치. 키트·외주 금지. **추가 재료비 12만 원 이하**(A02).
- 라인: **19mm 검은색**(A08, B03, 임전이양). 출발·도착 구역에 **100mm 수직선**이 있고, 정지 판정은 선을 덮는 방식으로 보입니다(A08, A09: "도착 구역 수직선 덮음 판단").
- 경로: 교차로에서 좌회전해 정지선에 정지하는 구조(A08), "교차형·격자 라인 트랙"(B04). 경기장 거리 D는 실측이 필요하다고 합니다(A02).
- 받침대: **중앙 기둥 위에 CD**가 놓입니다(A02, B08 "기둥 위 디스크"). "비고정 베이스"라서 부딪히면 밀릴 수 있습니다(임전이양, 추정이 포함된 표현).
- 재출발 최대 2회, 3회째는 0점. 재출발 시 이송 점수가 0으로 초기화됩니다(A09; A08도 "최대 2회").
- 순위 기준에 무게·부피 최소화가 포함됩니다(A08). 출발·도착 구역에서 LED 4Hz 점멸, 주행 중 소등 시 가점이 있습니다(A08, B03, 팀 로봇).
- 일정: 13주차(11/24) 경진대회, 10·11주차 모의 경진대회. 공식 운영계획 PDF(`2026창의과제_운영계획-20260826c.pdf`)를 A02가 출처로 인용했으니 원문으로 확인하세요.
