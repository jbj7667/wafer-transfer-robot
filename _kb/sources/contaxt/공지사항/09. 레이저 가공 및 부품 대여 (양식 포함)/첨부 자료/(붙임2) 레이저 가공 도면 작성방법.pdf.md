## Page 1
레이저 가공도면 작성 시 주의사항
1. 아크릴 사이즈의 사각형 양 끝을 전부 채우면 안됩니다. (최소 5mm 이상은 남길 것)
- 아크릴의 원점을 잡는 작업은 오른쪽 상단을 기준으로 수동으로 세팅을 하기에 여유를 주어야 됩니다.
2. 선을 하나로 겹쳐서 작업해 주시기 바랍니다. (원형 제외)
- 아크릴 절약과 가공 시간 단축을 위해 선을 겹치기 바랍니다.
3. 선을 겹친 상태에서 중복선을 제거해주시기 바랍니다. 명령어: OVERKILL
- 가공 시간 단축과, 레이저 열로 인한 2차 변형(치수변화)이 일어나기에 중복선을 제거해주시기 바랍니다.
4. 도면층(Layer)을 추가하여 가공순서를 지정 하기바랍니다. (아래 참조)
- 작은 부품에 구멍(Hole)을 가공 하는 과정 중 아크릴을 지지하는 철판보다 외형이 작으면 구멍을 뚫기 전 바닥으로 떨어지니 지정하기
  바랍니다
5. 레이저 가공기에 입력할 도면은 .dxf (2007버전 이하)로 저장 되어야 하며, 아크릴 사이즈를 표현하는 사각 테두리는 지우기 바랍니다.
6. 도면 검사 및 부품대여서 승인은 아래와 같이 이루어집니다. (학부사무실에 도면을 지참할 땐 상단의 우측 도면처럼 출력해서 오기 바랍니다)
-도면, 부품대여서 작성 -> 담당교수님 승인-> 학부사무실 승인-> 4-511 준비실에서 부품대여-> 4-509 가공실 가공시작 


## Page 2
도면층(Layer) 생성 방법
1. 명령창에 Layer 입력
2. 해당 아이콘을 눌러 도면층을 추가한 뒤 이름, 색상 변경
3. 순서를 변경할 도면 선을 클릭 후, 도면층을 변경


## Page 3
작성된 도면 출력하는 법
1. 명령창에 print 또는 plot, 컨트롤 + P 입력으로 플롯 실행
2. 프린터를 설정 후 용지크기(A4), 도면방향 설정
3. 플롯 대상- 윈도우 – 우측의 윈도우를 눌러 오른쪽 사진과 같이 출력범위를 설정
4. 플롯 간격띄우기의 플롯의 중심을 체크하고, 배치에 적용
5. 미리보기 후 출력
