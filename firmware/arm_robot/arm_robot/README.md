# arm_robot — 팔 방식(θ-R-Z) 벤치 시제품 펌웨어 골격

Arduino Mega 2560, 시리얼 115200. 근거 문서: `public/docs/design/arm_option.md`, `arm_calc/kin_out.md`. 링크 길이 L=180(동일 링크).

## 파일
| 파일 | 역할 |
|---|---|
| `config.h` | 핀, 스텝 환산, 링크 치수, 소프트 한계, 속도·가속, 홈잉 파라미터 |
| `stepper3.h/.cpp` | Timer3 CTC 20 kHz 단일 ISR, DDA 위상 누산기로 3축 동시 STEP, 축별 사다리꼴, 리밋 폴링. **config.h 비의존** (병합용) |
| `arm_kin.h/.cpp` | CD 중심 극좌표 → (θ, φ), 특이점 가드, 6개 베이스 표, 헤딩 보정 |
| `arm_robot.ino` | 홈잉(Z→R→TH), 이동 시퀀스, 시리얼 콘솔 |

## 핀 (wafer_robot 과 비충돌)
| 축 | STEP | DIR | SLEEP | 리밋 |
|---|---|---|---|---|
| TH | 46 | 47 | 48 | D4 (스테이 캠, 홈) |
| R | 49 | 50 | 51 | D5 (φ=105° 접힘 끝) |
| Z | 36 | 37 | 38 | D2 (하단) |

D46 은 Timer5 OC5A 이나 wafer_robot 은 D44/D45 만 PWM 으로 쓴다. 좌표: TH = 방위 0..360(정면 0, 왼쪽 +, 홈 = 216°), R = φ(홈 105°), Z = mm(하단 리밋 0). 마이크로스텝(TH,R 1/8, Z 풀스텝)은 DRV8834 M0/M1 결선과 `config.h` 값을 맞춰야 한다.

## 콘솔 명령
| 명령 | 동작 |
|---|---|
| `h` | 전축 홈잉 (Z → R → TH, 각 축: 고속 → 후퇴 → 저속 → 영점, 타임아웃 시 FAULT, 진행 출력) |
| `g <th> <Rcd> <Z>` | 물리 단위 직접 이동 (θ 도, CD 중심 반경 mm, Z mm). 3축 동시, 예상 시간 출력 |
| `b <n>` | 베이스 n(1..6) 픽 자세. 한 방향 접근 규칙 시퀀스(R 운반 반경 → TH+Z → TH 감소 방향 접근 → R 펴는 방향 접근) |
| `p` | 스텝/단위 위치, R_cd, 리밋 상태, ISR 최대 점유율(%) |
| `x` | 정지 (이동 중에도 `x` 문자로 중단) |
| `s` | SLEEP 토글 (위상 상실, 재홈잉 필요) |
| `rep <n> <b1> <b2>` | b1↔b2 를 n회 왕복, 매 도착마다 `ARR i/n b=.. steps TH= R= Z=` 출력 후 `REP_DWELL_MS` 대기 |
| `trim <ax> <steps>` | 축 목표에 스텝 오프셋 가산 |
| `speed <ax> <sps>` | 축 최고 속도 변경 |
| `j <ax> <steps>` | (보조) 홈잉 전 원시 스텝 이동, 배선·방향 확인용 |
| `hc <psi>` | (보조) 헤딩 오차 ψ(deg). `b`/`rep` 은 θ−ψ 로 명령 (arm_option §1.3) |

## 스텝률 예산
arm_option §5.1: TH 2000 + R 1205 + Z 3000 = **합 6205 sps** (20 kHz 틱 → 한 축 최대 10 kHz). 이 설정은 Z 를 풀스텝(750 sps)으로 두어 최고속 합 4250 sps (TH 2000, R 1500, Z 750). Z 를 1/4 스텝(3000 sps)으로 바꾸면 6205 에 가까워진다. `p` 의 `isr=` 값이 틱당 점유율이며 100 에 닿으면 틱을 놓친다 (목표 15~30% 이하).

## 11/01 측정 절차(arm_option §7.2) 연결
- **A 반복정밀도**: 펜을 포켓 중심에 고정 → `h` → `rep 10 5 6`(5↔6 왕복, 운반 반경 경유). 매 도착 `ARR` 줄(스텝 수)과 종이 점을 대조. 한 방향 접근 (a)는 기본 동작, 반대 방향 (b)는 `trim` 으로 접근 오프셋을 바꿔 비교. 중단 행은 `rep 10 3 4`.
- **B 처짐**: `g <th> <Rcd> <Z>` 로 R_w = 100, 250, 322 에 해당하는 Rcd(=R_w+64)로 이동해 높이 측정.
- **D 전원**: `speed` 로 속도를 올리며 `rep` 중 팩 전압 min-hold, Mega 리셋 여부 관찰.
- **E 방향 추정**: 시제품 라인 코드와 별개. 결과 ψ 는 `hc` 로 입력해 `b` 에 반영.

## 알려진 한계 / 확인 필요
- 3축은 각자 사다리꼴이며 도착 시각이 같지 않다 (직선 보간 아님). 충돌 방지는 시퀀스(`b`)에서 R 접힘 후 TH 회전으로 처리.
- 방향 부호(`DIR_INV_*`, `HOME_DIR_*`), 마이크로스텝, 홈 좌표(TH 216°, 접근 방향 +)는 결선 후 실측해 `config.h` 갱신.
- 포크 IR/넥 스위치, 라인센서, BLE, 주행 모터는 이 스케치에 없다.
- 병합: `stepper3.*` 를 복사하고 `s3Begin()` 에 핀 표를 주면 된다. 단, wafer_robot `lift.cpp` 도 Timer3 를 쓰므로 Z 축을 stepper3 로 이관하고 `lift.*` 를 제거해야 한다. 1 kHz 제어 틱(Timer1)은 stepper3 와 독립이다.
- 컴파일 확인: arduino:avr:mega, 경고 0 (flash 17,244 B, RAM 680 B). 실기 동작은 미검증.
